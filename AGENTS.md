## 2. Архитектура экранов и зон (Схема «Крест»)

Камера перемещается между тремя локациями в рамках одной сцены (`MainGame.unity`):
```
                 [ ↑ Возврат в Shop ]
           +-------------------------------+
           |       (1) Greenhouse          |   <-- слева
           |         Оранжерея             |
           +-------------------------------+
                           ^
                           | (0 <-> 1)
                           v
+------------------+---------------+------------------+
|                  |   (0) Shop    |                  |
| [В Оранжерею] <--|  Торговый зал |--> [В Улучшения] |
|                  | (Центр / Хаб) |                  |
+------------------+---------------+------------------+
                           ^
                           | (0 <-> 2)
                           v
           +-------------------------------+
           |        (2) Upgrades           |   <-- снизу
           |      Дерево улучшений         |
           +-------------------------------+
                 [ ↑ Возврат в Shop ]
```

### Правила навигации:
1. **Индекс 0**: `Shop` (Торговый зал — центральный хаб).
2. **Индекс 1**: `Greenhouse` (Оранжерея — находится слева).
3. **Индекс 2**: `Upgrades` (Дерево улучшений — находится снизу).
4. **Ограничение переходов**: Переходы возможны **только через Торговый зал (0)**.
   * `0 -> 1` и `0 -> 2` — РАЗРЕШЕНЫ.
   * `1 -> 0` и `2 -> 0` — РАЗРЕШЕНЫ.
   * `1 <-> 2` напрямую — СТРОГО ЗАБЛОКИРОВАНЫ в `CanTransition(...)`.
5. **Защита от клик-спама**: Пока `IsMoving == true`, любые вызовы `GoToZone` игнорируются, а кнопки навигации временно деактивируются.

## 3. Навигационный контроллер: `ZoneCameraController.cs`
Расположение: `Assets/Scripts/Navigation/ZoneCameraController.cs`

### Публичные методы:
* `GoToZone(int index)` — переместиться в указанную зону с проверкой `CanTransition` и `IsMoving`.
* `GoToShop()` — перейти в Торговый зал (0).
* `GoToGreenhouse()` — перейти в Оранжерею (1).
* `GoToUpgrades()` — перейти в Дерево улучшений (2).
* `CanTransition(int from, int to)` — валидатор схемы переходов.
* `UpdateButtonVisibility(int activeZone)` — актуализировать видимость 4-х краевых кнопок.

### Краевые UI-кнопки (привязываются в Инспекторе):
* `buttonToGreenhouse` (левый край) — видна только в `Shop (0)`.
* `buttonToUpgrades` (нижний край) — видна только в `Shop (0)`.
* `buttonGreenhouseToShop` (правый край) — видна только в `Greenhouse (1)`.
* `buttonUpgradesToShop` (верхний край) — видна только в `Upgrades (2)`.
